  Deskland → лендинг. [Документ](https://claude.ai/artifact/Sq4GGkwf3q769hHcwQKmgp),
  детали в [modules/brand.md](modules/brand.md).

  тема по Windows, Figma в его аккаунте ([ADR-0007](decisions/0007-own-product-redesign.md)).
- Компоненты и иконки GradientDeck используем ([ADR-0008](decisions/0008-gradientdeck-assets.md)).
- Черновик [`brand/DESIGN.md`](../brand/DESIGN.md) v0.2 (после самопроверки: контраст, фокус, заголовок окна, состояния, пауза обоев при открытых настройках, режим «На рабочем столе»). План: прототип настроек в коде параллельно с Figma, Пляж и Луг параллельно.

## 2026-11-13 · Пляж и Луг, выбор темы (PR #2)

- Установщик из CI поставлен в `%LOCALAPPDATA%\DeskWall`. Обои встали в режиме Windows 11 24H2+

## 2026-11-13 · Прототип DeskWall (PR #1)

- Импортированный C#-код Deskland заменён монорепо DeskWall: хост на Rust + Tauri 2, позиции
  иконок через Shell API, пауза при полноэкранных окнах, трей, автозапуск; движок на three.js
  (WebGPU + WebGL2) с темой «Острова»; настройки на React 19 + Tailwind 4 (RU/EN); протокол с
  тестами формы; Biome, Vitest, Playwright, CI с неподписанной сборкой NSIS.
- PR: https://github.com/dreyn-dev/DeskWall/pull/1
