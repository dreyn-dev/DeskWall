## 2026-11-14 · «Проталины» по этапам, тень под подписями, «Живой год»

- «Проталины» доработаны в 6 этапов (рост волной, свет по часам, рельеф снега, детали кромки,
  общий ветер, редкие сценки: заяц со следами, ворона, купание синицы, погоня синиц). Подробно в
  [theme-thaw.md](modules/theme-thaw.md).
- Тень под подписями иконок для всех тем и ползунок в настройках
  ([wallpaper-page.md](modules/wallpaper-page.md)).
- «Живой год»: тема по дате (зима, весна, лето, осень) с плавной сменой сезонов,
  [ADR-0006](decisions/0006-living-year.md), [theme-year.md](modules/theme-year.md).
- Коммиты по этапу в локальной ветке на ПК Mark, не запушены (нет права пуша у аккаунта ПК).
- Дальше: план и макет перерисовки «Осеннего леса» в общий стиль, ждёт подтверждения Mark.

## 2026-11-13 · Тема «Проталины», лес из CC0-моделей

- Mark принял лес на кронах, отрендеренных из CC0-моделей Quaternius, с землёй из фотоскана
  Poly Haven. Обновлены превью леса в списке тем и в docs.
- Новая тема «Проталины» под суть продукта: спокойное снежное поле, вокруг иконок тает снег,
  растут трава и первые цветы, группы иконок дают одну проталину. Птицы, лужи с каплями,
  снежная крупа. Модуль: [theme-thaw.md](modules/theme-thaw.md).
- Всё пока в локальных ветках на ПК Mark (`feat/forest-theme` → `feat/thaw-theme`): у аккаунта
  ПК нет права пуша в репозиторий.

## 2026-11-13 · Тема «Осенний лес» (PR #6)

- Своя тема DeskWall: осенний лес с высоты, иконки на солнечных полянах, лиса, белки, стаи
  птиц, листопад, ветер, плывущие тени облаков. Без картинок: кроны, подстилка и звери рисуются
  кодом при запуске. Тени от крон учитывают высоту, поэтому у полога есть глубина.
- Поляны строятся тем же полем, что в «Луге», и сливаются вдоль рядов иконок (замечание Mark про
  «круглые острова»).
- Генерация картинок через Higgsfield была запрещена правами, поэтому всё нарисовано кодом.
- Проверено на ПК Mark (dev-сборка, 2560×1440, RTX 5070 Ti): ~13% одного ядра CPU, ошибок нет.
- Модуль: [theme-forest.md](modules/theme-forest.md). Дальше: отзыв Mark, сравнение с референсами.

## 2026-11-13 · Прототип DeskWall (PR #1)

- Импортированный C#-код Deskland заменён монорепо DeskWall: хост на Rust + Tauri 2, позиции
  иконок через Shell API, пауза при полноэкранных окнах, трей, автозапуск; движок на three.js
  (WebGPU + WebGL2) с темой «Острова»; настройки на React 19 + Tailwind 4 (RU/EN); протокол с
  тестами формы; Biome, Vitest, Playwright, CI с неподписанной сборкой NSIS.
- PR: https://github.com/dreyn-dev/DeskWall/pull/1
