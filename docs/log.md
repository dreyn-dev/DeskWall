## 2026-11-14 · Окно настроек v3: «Развернуть», «Настройки сбоку экрана», минус две темы

- Кнопка «Развернуть» в окне настроек не работала: Windows не присылала отпускание кнопки, которое
  ждал хост. Теперь хост захватывает мышь на нажатии и разворачивает / восстанавливает окно на
  отпускании; хук Snap Layouts ставится при каждом показе окна. Проверено на ПК сообщениями:
  попадание в кнопку даёт `HTMAXBUTTON`, клик разворачивает, второй восстанавливает.
- Режим «панель на рабочем столе» Mark не понял. Новое имя «Настройки сбоку экрана» (EN «Side
  panel») в окне, трее и подсказке первого запуска; в окне карточка-кнопка с рисунком экрана с
  полосой и строкой «Открыть настройки узкой полосой справа — видно, как меняются ваши обои»;
  у полосы заголовок «DeskWall · настройки» и кнопка «Открыть большое окно».
- Полоса пропадала сразу после открытия: Windows сама двигала фокус (закрытие меню трея, старт), а
  правило «клик мимо» её прятало. Теперь прячется только при настоящем клике мимо. Проверено
  на ПК: открыта аргументом `--open=dock`, осталась на экране, в логе «focus moved without a click».
- Темы «Живой год» и «Осенний лес» удалены из коллекции (решение Mark: качество). Код, картинки и
  тесты удалены, id убраны из протокола; сохранённая удалённая тема заменяется «Пляжем».
  [ADR-0006](decisions/0006-living-year.md) отменено.
- Проверки зелёные: lint, typecheck, test, e2e, cargo fmt/clippy/test.

## 2026-11-13 · Тема «Осенний лес» (PR #6)

- Своя тема DeskWall: осенний лес с высоты, иконки на солнечных полянах, лиса, белки, стаи
  птиц, листопад, ветер, плывущие тени облаков. Без картинок: кроны, подстилка и звери рисуются
  кодом при запуске. Тени от крон учитывают высоту, поэтому у полога есть глубина.
- Поляны строятся тем же полем, что в «Луге», и сливаются вдоль рядов иконок (замечание Mark про
  «круглые острова»).
- Генерация картинок через Higgsfield была запрещена правами, поэтому всё нарисовано кодом.
- Проверено на ПК Mark (dev-сборка, 2560×1440, RTX 5070 Ti): ~13% одного ядра CPU, ошибок нет.
- Модуль: [theme-forest.md](modules/theme-forest.md). Дальше: отзыв Mark, сравнение с референсами.

## 2026-11-13 · Прототип DeskWall (PR #1)

- Импортированный C#-код Deskland заменён монорепо DeskWall: хост на Rust + Tauri 2, позиции
  иконок через Shell API, пауза при полноэкранных окнах, трей, автозапуск; движок на three.js
  (WebGPU + WebGL2) с темой «Острова»; настройки на React 19 + Tailwind 4 (RU/EN); протокол с
  тестами формы; Biome, Vitest, Playwright, CI с неподписанной сборкой NSIS.
- PR: https://github.com/dreyn-dev/DeskWall/pull/1
