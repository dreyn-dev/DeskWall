# 0003. Позиции иконок только через Shell API

- Дата: 2026-11-13
- Статус: принято

## Контекст

Референс читает прямоугольники иконок через `LVM_GETITEMRECT` + `VirtualAllocEx` /
`ReadProcessMemory` в `explorer.exe`. Такое поведение срабатывает на антивирусах (референс сам
пишет об этом в FAQ).

## Решение

Только документированный путь: `IShellWindows::FindWindowSW(CSIDL_DESKTOP)` → `IShellBrowser` →
`IFolderView::GetItemPosition`, размер ячейки из `IFolderView::GetSpacing`. Чужую память не
читаем никогда (правило записано и в `AGENTS.md`).

## Альтернативы

Чтение памяти Explorer, как у референса. Отклонено из-за антивирусов и SmartScreen.

## Последствия

- Сейчас опрос раз в 250 мс на отдельном STA-потоке, в страницу уходят только изменения. План:
  перейти на события (`SetWinEventHook`).
- Размер иконки сейчас равен шагу сетки, а не реальному размеру в текущем режиме вида.
