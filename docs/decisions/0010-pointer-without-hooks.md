# 0010. Курсор для обоев: опрос позиции, без перехвата мыши

- Дата: 2026-11-14
- Статус: принято
- Кто решил: Claude по просьбе Mark о пасхалках

## Контекст

Mark попросил пасхалки и реакцию на курсор во всех темах. Окно обоев лежит под слоем иконок, мышь
до него не доходит. Нельзя ломать клики по иконкам и выделение рамкой.

## Решение

Хост опрашивает `GetCursorPos`/`WindowFromPoint`/`GetAsyncKeyState` в своём потоке и отправляет
позицию, только когда курсор над самим рабочим столом. Мышь никто не перехватывает.

## Альтернативы

- Глобальный хук мыши `WH_MOUSE_LL`: точнее ловит быстрые клики, но вмешивается в весь ввод
  системы, его не любят антивирусы, а зависание хука тормозит мышь. Нет.
- Сделать окно обоев поверх иконок прозрачным для кликов: ломает иконки. Нет.

## Последствия

- Очень короткий клик (меньше ~16 мс) может не засчитаться. Для пасхалок это не важно.
- Новое событие `deskwall://pointer` в протоколе (TS и Rust, тест формы).
