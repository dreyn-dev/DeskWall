# 0013. Удалить темы, похожие на Deskland: Пляж, Луг, Острова

- Дата: 2026-11-20
- Статус: принято
- Кто решил: Mark

## Контекст

Пляж (Tideline), Луг (Daydream Meadow) и Острова (Drift Isles) после переписывания своим кодом
(ADR-0009) всё равно узнаются как сцены Deskland: тот же образ (песок и море, облака над лугом,
острова-топокарта). Остальные темы уже свои по образу.

## Решение

- Удаляем все три темы. Вместо них две новые свои темы на `kit.js`: «Созвездия» (`stars`) и
  «Иней» (`frost`), выбраны Mark из 4 концептов (`/mnt/project-files/deskwall-concepts-4/`).
- Тема по умолчанию: «Тихие камни» (`zen`). Сохранённые `beach`, `meadow`, `isles` (в том числе для
  отдельных мониторов) при загрузке заменяются темой по умолчанию.
- Острова были единственной темой на движке three.js: страница обоев больше не подключает
  `@deskwall/engine` (кроме `demoLayout` для демо-иконок). Сам пакет пока остаётся в репозитории.
- В NOTICE упоминание Deskland сокращено, но остаётся: первый коммит (исходник Deskland),
  способ прикрепления окна в `windows.rs` и поле и штрихи травы «Проталин».

## Альтернативы

- Ещё раз перерисовать Пляж и Луг: образ всё равно останется образом референса.
- Убрать NOTICE полностью: нельзя, пока в коде есть производные от Deskland части (GPL-3.0).

## Последствия

- Ветка тем без three.js: приложение меньше. Настройки только для Островов (`palette`,
  `landReach`, `roughness`, `motion`, `contours`) пока остаются в протоколе без интерфейса; убрать
  их вместе с пакетом `packages/engine` отдельной задачей.
- Чтобы убрать упоминание Deskland совсем, надо переписать «Проталины» на `kit.js`.
