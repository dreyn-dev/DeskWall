# 0014. Скрыть «Тихие камни» и «Иней» на доработку, основная тема «Светонить»

- Дата: 2026-11-20
- Статус: принято
- Кто решил: Mark

## Контекст

Mark: «Тихие камни» и «Иней» выглядят слабее других тем, в приложении он их пока видеть не хочет.
Когда их дорабатывать, пока не решено. «Тихие камни» были основной темой.

## Решение

- Темы скрыты, код остаётся: `HIDDEN_THEME_IDS` в `packages/protocol` (`zen`, `frost`). В списке
  тем их нет, сохранённая тема или тема монитора `zen`/`frost` переходит на основную. Их
  параметры в настройках сохраняются, чтобы после доработки тема вернулась как была.
- Основная тема теперь «Светонить» (`mycelium`), выбор Mark на карточке.
- `?hidden` в адресе окна настроек или обоев показывает скрытые темы (сборка `pnpm tauri dev`,
  браузер, тесты). Приложение само так окна не открывает. E2e-тесты этих тем идут через `?hidden`.

## Альтернативы

- Удалить темы, как Пляж и Луг (ADR-0013): Mark хочет их доработать, удалять рано.
- Оставить в списке с пометкой «скоро»: Mark не хочет видеть их в приложении.

## Последствия

- Вернуть тему: убрать её id из `HIDDEN_THEME_IDS` (и при желании сделать основной).
- Хосту на Rust id тем не нужны, `protocol.rs` не менялся (кроме примера в тесте).
