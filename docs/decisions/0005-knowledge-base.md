# 0005. База знаний в docs/ и запись итогов

- Дата: 2026-11-13
- Статус: принято
- Кто решил: Mark

## Контекст

Проект долгий, работа идёт в разных тредах Claude. Новый тред не помнит контекст старого, и Mark
приходится повторять одно и то же.

## Решение

- Источник правды о проекте: `docs/` в репозитории. Индекс `docs/README.md`, по файлу на модуль,
  по файлу на решение, журнал `docs/log.md`, процесс `docs/process.md`.
- Принцип «1 модуль = 1 задача = 1 файл», общее в одном месте.
- Каждая работа заканчивается обновлением документов в том же PR.
- Память проекта Claude хранит только короткую сводку и ссылки на `docs/`.

## Последствия

- `AGENTS.md` (он же `CLAUDE.md`) отправляет каждую сессию сначала в `docs/README.md`.
- Доска задач в Notion вторична: статус модулей живёт в `docs/`.
