# 0007. Свой продукт: имя DeskWall, свой стиль, Пляж и Луг переписываем

- Дата: 2026-11-14
- Статус: принято
- Кто решил: Mark

## Контекст

Mark решил сделать из прототипа самостоятельный продукт: концепция (обои под иконками, жизнь
растёт из иконок) остаётся, визуал новый, связи с референсом Deskland убираем. Исследование и
план: [документ](https://claude.ai/artifact/Sq4GGkwf3q769hHcwQKmgp), итоги в
[modules/brand.md](../modules/brand.md).

## Решение

- Имя остаётся **DeskWall**.
- Темы «Пляж» и «Луг» доводятся до идеала и переписываются своим кодом на движке DeskWall
  (заменяет перенос 1:1 из [ADR-0004](0004-classic-themes-port.md)). После этого строка о
  перенесённых темах уходит из `NOTICE`.
- Шрифты только бесплатные (OFL) с кириллицей.
- Светлая или тёмная тема интерфейса следует настройке Windows.
- Макеты в Figma в аккаунте Mark.
- Лицензия не меняется: GPL-3.0 ([ADR-0001](0001-license-gpl3.md)).

## Альтернативы

Новое имя (отклонено: Mark нравится DeskWall). Удалить Пляж и Луг (отклонено: на Луге держится
лето «Живого года»). Платные шрифты референсов (отклонено).

## Последствия

- Компоненты и код без лицензии (например, AI-компоненты gradientdeck.com) не используем.
- Порядок работ: `brand/DESIGN.md` → Figma → окно настроек → переписать Пляж и Луг → лендинг.
