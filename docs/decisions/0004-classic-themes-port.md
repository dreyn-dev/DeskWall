# 0004. Пляж и Луг переносим почти 1:1

- Дата: 2026-11-13
- Статус: принято
- Кто решил: Mark

## Контекст

Свой визуальный стиль появится только на шаге 3 (Figma). Нужны готовые красивые темы уже сейчас.

## Решение

Темы «Пляж» и «Луг» референса переносятся почти без изменений: страницы WebGL2 в same-origin
iframe, тот же протокол сообщений (`ready`, `icons`, `settings`, `pause`). Изменения только два:
скрипт вынесен из HTML (CSP Tauri) и транспорт заменён на `postMessage` к родителю. Перенос
воспроизводится скриптом `tools/vendor_classic_themes.py`. **Пляж** стал темой по умолчанию.
Своя тема «Острова» на движке DeskWall остаётся рядом.

## Альтернативы

Переписать темы на движок DeskWall сразу. Отложено: долго, а стиль всё равно поменяется.

## Последствия

- Атрибуция в `NOTICE` и в заголовках файлов тем.
- Открытый вопрос: остаются ли эти темы в публичном релизе (план MVP предлагал оставить их только
  в прототипе и выпустить две свои).
