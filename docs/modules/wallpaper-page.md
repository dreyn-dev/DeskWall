# Модуль: Страница обоев

- **Статус:** прототип
- **Код:** `apps/desktop/wallpaper.html`, `apps/desktop/src/wallpaper/{main,surface,labelVeil}.ts`
- **Связанные решения:** ADR-0004
- **Обновлено:** 2026-11-16

## Назначение

Веб-страница внутри окна обоев. Получает события хоста и передаёт их активной теме через общий
интерфейс `Surface` (`setIcons`, `setSettings`, `setPaused`).

## Устройство

- `surface.ts`: выбирает реализацию по теме. Своя тема → движок ([engine](engine.md)).
  Классическая тема → same-origin iframe со страницей темы в режиме `?wallpaper`: ждёт `ready`,
  затем шлёт `settings`, `pause`, `icons` (прямоугольники переводятся в `[l,t,r,b]` в физических
  пикселях).
- `main.ts`: в приложении подписывается на события хоста и вызывает `wallpaper_ready`; в браузере
  или вне Windows запускает демо из 13 перетаскиваемых иконок. Смена темы перезагружает страницу.
  Параметры URL: `?embed` (превью в настройках, без HUD и перетаскивания), `?hud`,
  `?renderer=webgl`, `?screen=<id>` (окно на дополнительном мониторе: тема из
  `screenThemes[id]`, иначе тема основного, ADR-0011).
- `labelVeil.ts`: мягкая холодная тень под подписями иконок поверх любой темы (2D-холст между
  темой и иконками). Сила = `Settings.labelVeil` × `ThemeDef.labelVeil` (насколько светлая тема:
  «Проталины» 1, «Пляж» 0,8, «Луг» 0,7, «Острова» 0,6, «Лес» 0,35). Перерисовывается только при
  смене иконок или силы, в каждом кадре ничего не делает.
