# Модуль: Рабочий стол Windows

- **Статус:** прототип, проверен на Win11 24H2
- **Код:** `apps/desktop/src-tauri/src/desktop/{mod,windows}.rs`
- **Связанные решения:** ADR-0003
- **Обновлено:** 2026-11-13

## Назначение

Встраивает окно обоев под слой иконок, читает позиции иконок, определяет, что обои закрыты
полноэкранным окном. На других ОС (`mod.rs`) показывает обои обычным окном с демо-иконками для
разработки.

## Устройство

Один STA-поток (`watcher`) опрашивает раз в 250 мс:

1. **Прикрепление** (`attach`): Win11 24H2+ — слоёное дочернее окно `Progman` прямо под
   `SHELLDLL_DefView`; старые системы — классический `WorkerW`. Если Explorer перезапустился или
   сменил родителя, прикрепляется заново. `keep_z_order` держит окно под иконками.
2. **Иконки** (`read_icons`): `IFolderView::Items` + `GetItemPosition`, размер из `GetSpacing`,
   координаты переводятся в клиентские координаты окна обоев. Флаг `visible` берётся из видимости
   list-view (настройка «Показывать значки»).
3. **Полный экран** (`foreground_covers_wallpaper`): `SHQueryUserNotificationState` и проверка
   окна на переднем плане.

При выходе (`shutdown`) окно отсоединяется и системные обои применяются заново, чтобы стол
перерисовался.

## Что сделано

- Прикрепление в обоих режимах, иконки через Shell API, пауза при полном экране (PR #1).
- Проверено на ПК Mark: Win11 24H2, режим 24H2+.

## Известные проблемы и ограничения

- Встраивание под иконки — недокументированное поведение Windows, Microsoft меняла его в 24H2.
- Покрывает только основной монитор.

## Как проверить

С Linux/macOS: `cargo clippy --target x86_64-pc-windows-msvc --all-targets -- -D warnings`.
Вживую: установить `nightly` на Windows, посмотреть лог в `%LOCALAPPDATA%\app.deskwall.desktop\logs`
(строка `wallpaper attached: ...`).
