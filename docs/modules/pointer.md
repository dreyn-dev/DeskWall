# Модуль: Курсор на обоях (пасхалки)

- **Статус:** прототип, ждёт проверки на ПК
- **Код:** `apps/desktop/src-tauri/src/desktop/windows.rs` (`pointer_watcher`), событие
  `deskwall://pointer` в `packages/protocol` и `protocol.rs`, `src/wallpaper/{main,surface}.ts`,
  `classic/kit.js`, `thaw.js`, `packages/engine/src/scene.ts` (`setPointer`)
- **Связанные решения:** ADR-0010
- **Обновлено:** 2026-11-14

## Назначение

Темы реагируют на курсор и клики по пустому месту рабочего стола (просьба Mark 2026-11-14).

## Устройство

- Обои лежат под слоем иконок, Windows не шлёт им мышь. Хост в отдельном потоке смотрит, где
  курсор (`GetCursorPos` + `WindowFromPoint`), и если под ним сам рабочий стол (список иконок
  `SysListView32` или Progman/WorkerW), шлёт позицию и состояние левой кнопки (учтена смена
  кнопок местами). ~60 раз в секунду над рабочим столом, ~11 раз иначе. Ничего не
  перехватывается: клики по иконкам, рамка выделения, меню рабочего стола работают как раньше.
- Страница обоев пересчитывает в CSS-пиксели и передаёт теме (`{t:'pointer', in, x, y, down}`
  для классических страниц, `setPointer` для движка). В браузере (демо) берутся обычные события
  мыши.
- «Клик» в теме: нажали и отпустили быстрее 0,6 с, сдвиг меньше 8 px, не на иконке.

## Пасхалки по темам

- Пляж и Луг: см. [theme-beach.md](theme-beach.md), [theme-meadow.md](theme-meadow.md).
- Проталины: птицы на земле вспархивают от курсора, бабочки разлетаются; клик по проталине:
  волна весны и новые цветы; клик по снегу: морозный круг; 3 быстрых клика по снегу: прибегает
  заяц.
- Острова: мягкий свет вокруг курсора; клик по воде: круги; клик по суше: бумажный холмик
  подпрыгивает; 5 быстрых кликов в одно место: на ~40 секунд поднимается маленький остров.

курсором по пустому рабочему столу.
