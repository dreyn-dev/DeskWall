# Модуль: Тема «Созвездия» (Constellations, id `stars`)

- **Статус:** своя, прототип; ждёт проверки Mark на ПК
- **Код:** `apps/desktop/public/themes/classic/stars.{html,js}` на `kit.js`, `thumbs/stars.webp`;
  параметры в `apps/desktop/src/shared/themes.ts`
- **Связанные решения:** ADR-0013
- **Обновлено:** 2026-11-20

## Назначение

Спокойное ночное небо. Вокруг каждой группы иконок мягкая туманность, звёзд там больше, яркие
звёзды кольцом вокруг группы соединены в созвездия, поэтому ряд или столбец иконок получает одну
общую фигуру. Середина экрана тёмная, только редкая звёздная пыль. Концепт выбран Mark 2026-11-20
(`/mnt/project-files/deskwall-concepts-4/4-stars-*.png`).

## Устройство

- Небо: один полноэкранный проход по полю иконок (`Field` + `Morph`): градиент неба, туманность
  (`fbm`, медленно плывёт) только у групп, два слоя звёздной пыли по ячейкам (одна звезда на
  ячейку, вероятность растёт у иконок, мерцание по хэшу ячейки).
- Созвездия: точки на линии поля `s = 34` (`contourPoints`, шаг 46 px), сдвиг наружу и разброс по
  хэшу места (группа, которая не двигалась, сохраняет свою фигуру), у части звёзд «рукава» наружу,
  связь с ближайшей соседкой до 120 px. Рисуются одним instanced-вызовом `Segs` (линии и звёзды
  со свечением и лучами), при перестановке иконок старые созвездия гаснут, новые проявляются (2,4 с).
- Клик: падающая звезда от курсора, на месте клика загорается новая звезда и гаснет за ~1 мин.
  Курсор над пустым небом оставляет звёздную пыль. Пасхалка: раз в 45–155 с метеор через небо.
- Настройки: Туманность, Сколько звёзд, Линии созвездий, Небо (Ночное синее, Фиолетовая дымка,
  Бирюзовое, Чернильное), Следов от кликов сразу. Подписи: `labelVeil` 0,2.
