# Модуль: Тема «Пляж» (Beach)

- **Статус:** перенесена из Deskland, тема по умолчанию
- **Код:** `apps/desktop/public/themes/classic/beach.{html,js}`, `beach-palms.js`, `assets/beach-*.png`,
  `thumbs/beach.webp`; параметры в `apps/desktop/src/shared/themes.ts`
- **Связанные решения:** ADR-0001, ADR-0004
- **Обновлено:** 2026-11-13

## Назначение

Берег огибает файлы, волны набегают на песок, пальмы, байдарки, птицы.

## Устройство

Самостоятельная страница WebGL2 референса (исходник `prototype/flat.html`), работает в iframe
[страницы обоев](wallpaper-page.md). Параметры (диапазоны как в `themes.json` референса):
`sigma` (расстояние до берега), `warp` (извилистость), `shoal`, `shallow`, `palms`, `kayaks`,
`birds`.

Код темы не правим руками: перенос повторяется скриптом
`python3 tools/vendor_classic_themes.py /путь/к/Deskland/prototype`.

## Что сделано

- Перенос, параметры в настройках, тема по умолчанию (PR #2).

## Известные проблемы и ограничения

- Шейдер на GLSL, не на TSL: исключение из правил движка, пока тема перенесена как есть.
- Ассеты тяжёлые (PNG пальм по ~1.6–1.9 МБ).

## Как проверить

`pnpm e2e` (тест классических тем); скриншот `docs/images/classic-beach.webp`.
