# Модуль: Бренд

- **Статус:** рабочий вариант для прототипа
- **Код:** `brand/` (`mark.svg`, `mark-1024.png`, `README.md`), иконки `src-tauri/icons/`,
  `TRADEMARKS.md`, токены в `apps/desktop/src/settings/styles.css`
- **Связанные решения:** ADR-0001
- **Обновлено:** 2026-11-14

## Назначение

Имя, знак, цвета и шрифт DeskWall. Отличается от бренда Deskland (требование их TRADEMARKS.md).

## Устройство

- Знак: террасный остров на тёмной воде в скруглённой плитке.
- Цвета: ink `#071521` / `#0b1f30` / `#12304a`, tide `#2ec4b6`, sand `#f2d7a6`, fog `#e8f1f5`.
- Шрифт: Segoe UI Variable, системный запасной.

## Подготовка нового дизайна (2026-11-14)

Исследование и план: [документ](https://claude.ai/artifact/Sq4GGkwf3q769hHcwQKmgp). Итоги:

- AI-компоненты gradientdeck.com не берём: они для чатов и агентов, и у их кода нет лицензии
  (нельзя класть в GPL-репозиторий). Пригодятся генераторы (mesh, палитры, блобы), MIT-скилл
  для лендинга и библиотека DESIGN.md как учебник.
- Стиль: каркас Unseen Studio (сцена на весь экран, плоские маленькие контролы, панель сбоку,
  дуэт тонкой антиквы и гротеска), из Codex тёмный режим и «один акцент», из Eclipse ярлыки.
- Шрифты: OFL с кириллицей (Cormorant, Onest или Inter, JetBrains Mono), если Mark не решит иначе.
- Решения Mark (2026-11-14): имя остаётся **DeskWall**; Пляж и Луг доводим до идеала и
  переписываем своим кодом ([ADR-0007](../decisions/0007-own-product-redesign.md)); шрифты только
  бесплатные; светлая/тёмная тема по настройке Windows; Figma в аккаунте Mark.
