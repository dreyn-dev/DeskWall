# Модуль: Окно настроек

- **Статус:** прототип нового дизайна в двух вариантах (A «Окно», B «На рабочем столе»), ждёт выбора Mark
- **Код:** `apps/desktop/index.html`, `apps/desktop/src/settings/` (`App.tsx` варианты A и B,
  `Panel.tsx` общее содержимое панели, `ui.tsx` компоненты, `TitleBar.tsx`, `bridge.ts` состояние и
  связь с хостом, `i18n.ts`, `styles.css` токены); общее: `apps/desktop/src/shared/{themes,host}.ts`
- **Связанные решения:** [ADR-0007](../decisions/0007-own-product-redesign.md),
  [ADR-0008](../decisions/0008-gradientdeck-assets.md), источник правды по стилю
  [`brand/DESIGN.md`](../../brand/DESIGN.md) v0.2
- **Обновлено:** 2026-11-14

## Назначение

Окно, где выбирают тему и настраивают её. Сохраняет настройки и рассылает их окну обоев.

## Устройство

- Один `index.html`, режим по адресу: без параметра вариант A, `?mode=dock` вариант B.
- **Вариант A «Окно»** (окно `settings`, 1200×760, минимум 960×640, без системной рамки): живое
  превью `wallpaper.html?embed&inset=80` на всё окно в масштабе 0.75 (выглядит как рабочий стол;
  `inset` отодвигает фейковые иконки от кнопок), строка заголовка 40 px с кнопками Windows
  (`data-tauri-drag-region`, двойной клик разворачивает), круглые кнопки: меню (две точки → крестик)
  и пауза превью справа сверху, «Открыть панелью на рабочем столе» справа снизу; внизу слева
  пилюля с номером и именем темы и ярлык «WEBGL2 · 30 FPS». Панель 400 px справа въезжает за
  240 мс; Esc закрывает её и возвращает фокус на кнопку меню. Пока окно открыто и не свёрнуто,
  обои на рабочем столе на паузе (причина `settings`).
- **Вариант B «На рабочем столе»** (окно `dock`): панель 400 px у правого края рабочей области
  основного монитора, поверх настоящих обоев, без превью. Строка заголовка без «Развернуть»,
  подсказка «Смотрите на рабочий стол», пилюля «Открыть полное окно». Обои не на паузе: результат
  виден на своих иконках. Esc прячет панель.
- Содержимое панели одинаковое (`Panel.tsx`): список тем крупным Cormorant с номерами 01–06
  (текущая тема `stone` с подчёркиванием), описание, параметры активной темы из
  `shared/themes.ts` (ползунки, переключатели, выбор чипами), для «Островов» палитра и пейзаж,
  затем «Общие»: тень под подписями, FPS 15/30/60 чипами, пауза при полном экране, автозапуск
  (только в приложении), язык (System / English), сброс.
- Окна держат настройки в одном store: при фокусе окно перечитывает его, поэтому A и B не
  расходятся.
- Состояния превью: «Сцена растёт» до первого кадра; ошибка темы (`data-error` страницы обоев) →
  текст `danger` и «Перезапустить тему»; «Работает в режиме совместимости», если «Острова» ушли на
  WebGL2; «Пауза ·» в ярлыке, если превью на паузе.
- Стиль: токены DESIGN.md в `@theme` Tailwind 4 (`styles.css`), светлая и тёмная тема по Windows
  (`prefers-color-scheme`), `forced-colors`, `prefers-reduced-motion`, кольцо фокуса 2 px (поверх
  сцены двойное). Шрифты OFL из пакетов `@fontsource` (Cormorant 300 и 300 italic, Onest 400/500,
  JetBrains Mono 400; только латиница и кириллица) вшиты в сборку. Иконки lucide-react.
- `i18n.ts`: словари EN и RU. В списке языков только «System» и English. Русский включается
  только через «System», когда первый язык Windows русский (хост отдаёт список командой
  `system_locales`). Меню в трее следует тому же правилу.
- Трей: «Настройки» открывает A, «Панель на рабочем столе» открывает B, клик по значку открывает
  A; в dev-сборке флажок «Прототип: клик по значку открывает панель» переключает клик на B.

## Открытые задачи

- [ ] Mark выбирает вариант A или B (или оба: B из трея, A для первого запуска), лишнее убрать

- [ ] Строка заголовка в A всегда с подложкой `snow` 60% (по DESIGN.md только при прокрутке):
  без неё в тёмной теме подпись не читается на светлой сцене. Решить в Figma.
- [ ] Чипы-фильтры тем («Все», «Сезоны», «Море»), когда тем станет больше.
- [ ] Новый знак DeskWall (сейчас старый остров в заголовке).
- [ ] Экспорт PNG для соцсетей.
- [ ] ICU MessageFormat (Lingui), когда строк станет больше.

## Известные проблемы

- Вариант B ставится на основной монитор; на втором мониторе панель не появится.
- В варианте A превью живёт в `iframe` и рисует фейковые иконки; на тёмных темах Windows сцена
  остаётся светлой (у сцены свои цвета).
- Окно `dock` не прячется при клике мимо: закрывается крестиком или Esc.

## Как проверить

- Браузер: `pnpm --filter @deskwall/desktop dev` → `http://localhost:5180/` (вариант A),
  `http://localhost:5180/?mode=dock` (вариант B); `?renderer=webgl` для WebGL2.
- Приложение: `pnpm tauri dev` (установленный DeskWall из `%LOCALAPPDATA%\DeskWall` должен быть
  остановлен), затем трей → «Настройки» (A) или «Панель на рабочем столе» (B).
- Тесты: `pnpm test` (i18n), `pnpm e2e` (оба варианта). На ПК Mark нет браузера Playwright: запускать
  с `PW_CHROMIUM_PATH="C:/Program Files/Google/Chrome/Application/chrome.exe"`.
