# Модуль: Окно настроек

- **Статус:** прототип
- **Код:** `apps/desktop/index.html`, `apps/desktop/src/settings/` (`App.tsx`, `main.tsx`, `i18n.ts`,
  `styles.css`); общее: `apps/desktop/src/shared/{themes,host}.ts`
- **Обновлено:** 2026-11-13

## Назначение

Окно, где выбирают тему и настраивают её. Сохраняет настройки и рассылает их окну обоев.

## Устройство

- `App.tsx`: живое превью (iframe `wallpaper.html?embed`), выбор темы с миниатюрами, параметры
  активной темы, общие настройки (fps, пауза при полном экране, автозапуск, язык).
- `shared/themes.ts`: каталог тем (id, имена RU/EN, описание, миниатюра, страница, параметры с
  min/max/default/формат). Добавить тему = добавить запись сюда и id в протокол.
- `shared/host.ts`: загрузка и сохранение настроек (store плагина в приложении, `localStorage` в
  браузере).
- `i18n.ts`: словари EN и RU. В списке языков только «System» и English. Русский включается
  только через «System», когда первый язык Windows русский (хост отдаёт список командой
  `system_locales`). Меню в трее следует тому же правилу.
- Стиль: Tailwind 4, токены бренда в `styles.css`.
