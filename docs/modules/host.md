# Модуль: Хост (Tauri)

- **Статус:** прототип работает
- **Код:** `apps/desktop/src-tauri/src/{lib,state,tray,main}.rs`, `tauri.conf.json`, `capabilities/`
- **Связанные решения:** ADR-0002
- **Обновлено:** 2026-11-16

## Назначение

Нативное приложение: жизненный цикл, окна, трей, автозапуск, один экземпляр, хранение настроек и
рассылка событий страницам. Работу с рабочим столом Windows делегирует модулю
[desktop-windows](desktop-windows.md).

## Устройство

- `lib.rs`: сборка Tauri, плагины (`single-instance`, `log`, `store`, `autostart`), команда
  `wallpaper_ready` (страница сообщает о готовности, хост сразу шлёт иконки и паузу и отвечает
  `{ native }`), `system_locales` (языки интерфейса Windows), `open_settings(mode)` (`window` или
  `dock`, режим A или B окна настроек, запоминается в `trayOpens`), `set_dock_pinned` и
  `load_stats` (CPU/GPU DeskWall, `load.rs`). Состояние `HostState` регистрируется до создания
  окон: страница обоев может позвать `wallpaper_ready` раньше, чем закончится `setup`. Слушает событие настроек, чтобы
  применить `pauseOnFullscreen` и язык трея.
- `state.rs`: `HostState`, общий для потока наблюдателя, трея и настроек. Хранит последние иконки
  и паузу, шлёт только изменения. Причины паузы: `user`, `fullscreen`, `locked`; пауза `settings` убрана 2026-11-17 (было: открыто окно
  настроек с живым превью: две сцены сразу удваивают нагрузку на GPU).
- `tray.rs`: меню «Окно настроек / Настройки сбоку экрана / Пауза / Перезагрузить сцену / Выход»;
  клик по значку открывает режим из `trayOpens`. Ставит панель `dock` к правому краю рабочей
  области монитора под курсором (над панелью задач, с учётом DPI), прячет её при потере фокуса,
  если не закреплена;
- `chrome.rs`: Snap Layouts на своей кнопке «Развернуть» окна настроек (`WM_NCHITTEST` →
  `HTMAXBUTTON` через прозрачное дочернее окно), событие `deskwall://caption` для подсветки.
- `load.rs`: нагрузка CPU по дереву наших процессов и GPU по счётчикам PDH «GPU Engine». подписи RU, если `locale` = `auto` и
  Windows на русском, иначе EN.
- `locale.rs`: языки пользователя Windows. Сначала порядок из «Параметры → Время и язык → Язык»
  (реестр `HKCU\Control Panel\International\User Profile\Languages`), затем язык интерфейса.
  Русский, если первый в списке русский. Нужно, потому что у Mark язык интерфейса en-US (нет
  языкового пакета), а первым в списке стоит ru.
- Окна: `wallpaper` (основной монитор, невидимое до прикрепления) и `wallpaper-<id>` на остальных
  мониторах (создаются на лету, ADR-0011; `HostState` хранит иконки, паузу и «полный экран» по
  каждому окну), `settings` (без системной рамки, своя строка
  заголовка; закрытие прячет окно, приложение остаётся в трее) и `dock` (панель 400 px без рамки,
  не в панели задач). Запуск с `--autostart` не открывает настройки.
- Настройки хранятся в `settings.json` плагина store; CSP разрешает только `'self'`.

## Что сделано

- Хост, трей, автозапуск, один экземпляр, логи (PR #1).
- Окно `dock`, команда `open_settings`, пауза `settings`, пункты трея для режимов A и B; затем
  запоминание режима, закрепление панели, Snap Layouts, нагрузка CPU/GPU (ветка
  `feat/settings-redesign`, 2026-11-14, локально).

## Известные проблемы и ограничения

- Окно настроек больше не ставит обои на паузу (2026-11-17): раньше они замирали, и казалось, что тема «не
  запускается». Причины паузы: `user`, `fullscreen`, `locked`.

- Только основной монитор, одно окно обоев.

## Как проверить

`cargo fmt --check && cargo clippy --all-targets -- -D warnings && cargo test` в `src-tauri`;
`pnpm tauri dev` для запуска.
