# Модуль: Движок сцены

- **Статус:** прототип
- **Код:** `packages/engine/src/{field,scene,palettes,index}.ts`
- **Связанные решения:** ADR-0002
- **Обновлено:** 2026-11-13

## Назначение

Общая основа для своих тем DeskWall: из прямоугольников иконок строит поле высот, плавно морфит
его и рисует сцену на three.js. Сейчас на нём работает одна тема, [«Острова»](theme-isles.md).

## Устройство

- `field.ts` (чистые функции, есть тесты): прямоугольники иконок → SDF скруглённых прямоугольников,
  смешанные плавным минимумом (`smin`) на сетке; плюс суша, минус вода, единицы — CSS-пиксели.
  `reachPx` переводит настройку `landReach` в пиксели. `demoLayout` раскладывает демо-иконки.
- `scene.ts`: `WebGPURenderer` (WebGPU, автоматически WebGL2, или принудительно `?renderer=webgl`),
  шейдер на TSL. Поле загружается текстурой half-float; при смене иконок морф за ~900 мс с
  продолжением с текущего кадра. Кадры ограничены `settings.fps`, при паузе цикл стоит.
- `palettes.ts`: палитры Daybreak, Lagoon, Dusk, Nocturne.

Правила (из `AGENTS.md`): 30 fps по умолчанию, пауза когда закрыто, без аллокаций в кадре, тяжёлая
работа только при смене иконок, шейдеры только на TSL.

## Что сделано

- Поле, морф, рендер, палитры, ограничение fps (PR #1). Движок грузится лениво, только когда
  активна его тема (PR #2).
