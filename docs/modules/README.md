# Модули

Один модуль = один файл. Модуль соответствует папке или группе файлов в коде, у него один
ответственный файл документации. Новый модуль: копия [_template.md](_template.md) и строка в
таблице модулей в [../README.md](../README.md).

Как модули связаны:

```
Windows desktop ──► Хост (Rust/Tauri) ──события протокола──► Страница обоев ──► Поверхность
 (desktop-windows)    (host, tray, state)     (protocol)        (wallpaper-page)   └─ iframe классической темы
                            ▲                                                         (kit.js: Тихие камни, Созвездия, Иней…)
                            └──── настройки (store + событие) ◄──── Окно настроек (settings-ui)
```

Сборка и выпуск: [ci-release.md](ci-release.md). Имя, иконка, цвета: [brand.md](brand.md).
