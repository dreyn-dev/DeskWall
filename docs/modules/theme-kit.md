# Модуль: Основа классических тем (kit.js)

- **Статус:** основа всех классических тем, кроме «Проталин»
- **Код:** `apps/desktop/public/themes/classic/kit.js` (ES-модуль)
- **Связанные решения:** ADR-0009, ADR-0010
- **Обновлено:** 2026-11-16

## Назначение

Общий собственный код для страниц-тем, чтобы новая тема писалась только про свой пейзаж.

## Устройство

- Поле вокруг иконок: каждая иконка как скруглённый прямоугольник, «мягкий минимум» расстояний
  (log-sum-exp), поэтому соседние иконки сливаются в одну форму; плоскость слегка искривлена
  шумом для живого контура. Считается на CPU только при изменении иконок, в GPU уходит
  half-float текстурой; `Morph` плавно переводит старую форму в новую.
- Свет по времени суток (`dayLight`: тон кадра, тёплый свет, длина теней, направление солнца),
  один ветер на всё (`windAt` на CPU и тот же `WIND_GLSL` в шейдерах).
- Спрайты: атлас рисуется кодом при старте (`Atlas`), пакетная отрисовка (`Sprites`) с мягкими
  тенями: силуэты в буфер половинного разрешения, шейдер земли берёт их с размытием.
- `runPage`: демо-иконки при прямом открытии, режим обоев (`ready`, `icons`, `settings`, `reset`,
  `pause`, `pointer`), 30 fps, пауза, курсор (позиция, скорость, «клик по пустому месту»). На
  паузе после смены иконок, настроек или размера рисует один кадр (`st.dirty`), чтобы обои,
  загруженные при открытом окне настроек, всё равно показали землю у иконок.
- `CapMask` (2026-11-18, ветка `feat/isolines`): маска R8 на сетке поля, 1 в полосе под каждой иконкой; тема гасит там линии
  или цвет, чтобы подписи читались. `alloc()` после `field.resize`, `bake(icons)` при смене иконок, `bind(unit)` перед рисованием.
- Следы от кликов (круги, волны, тычки): сколько их сразу на экране, решает общая настройка
  `clicks` (1–32, по умолчанию 16, `clickParams` в `themes.ts`); массивы в шейдерах на
  `MAX_CLICKS` = 32, следующий слот `nextClick(i, P)`. **Правило Mark (2026-11-16): в темах,
  нынешних и будущих, число одновременных следов не зашивать, только через эту настройку.**

  «Инея». Пляж и Луг удалены (ADR-0013).
