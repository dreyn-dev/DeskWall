# Модуль: «Живой год» (year)

- **Статус:** прототип
- **Код:** `apps/desktop/src/shared/year.ts` (сезон по дате, тест `year.test.ts`),
  `apps/desktop/src/wallpaper/surface.ts` (`createYearSurface`), запись `year` в
  `apps/desktop/src/shared/themes.ts`, превью `thumbs/year.webp`
- **Связанные решения:** [ADR-0006](../decisions/0006-living-year.md)
- **Обновлено:** 2026-11-14

## Назначение

Один мир, который живёт по календарю: зимой снег с маленькими проталинами у иконок, весной
проталины растут и зацветают, летом луг, осенью лес.

## Устройство

- `seasonScene(date, { season, south })` возвращает тему и её параметры на дату. Весна идёт
  плавно: размер проталин 80 → 150 px, цветы ×0,3 → ×1,3, крупа уходит.
- Поверхность «Живого года» держит одну классическую страницу. Раз в 5 минут (и при смене
  настроек) пересчитывает сезон: та же тема получает новые параметры, другая тема запускается
  под текущей, растит пейзаж 2,5 с и проявляется за 4 с.
- Параметры: «Время года» (по дате / зима / весна / лето / осень), «Южное полушарие».

## Что сделано

- Режим, выбор сезона, плавная смена тем, e2e-тест смены сезона (2026-11-14).

## Открытые задачи

- [ ] Перерисовать «Осенний лес» в общий светлый стиль, чтобы осень выглядела тем же миром
  (ждёт подтверждения Mark по плану и макету).
- [ ] Зима: свой вид проталин без зелёной полянки (сейчас та же полянка, что весной, только
  меньше и без цветов).

## Как проверить

Настройки → «Живой год» → «Время года»: переключать сезоны и смотреть смену. В браузере:
`http://localhost:5180/wallpaper.html` с темой `year`; `pnpm e2e` (тест `living year ...`).
