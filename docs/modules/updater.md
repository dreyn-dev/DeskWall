# Модуль: Автообновление

- **Статус:** прототип, ждёт проверки Mark и первого релиза
- **Код:** `apps/desktop/src-tauri/src/updater.rs`, `plugins.updater` в `tauri.conf.json`,
  `tauri.release.conf.json`, `.github/workflows/release.yml`, `src/settings/` (блок «Обновления»)
- **Связанные решения:** [ADR-0012](../decisions/0012-auto-update.md)
- **Обновлено:** 2026-11-17

## Назначение

Приложение само находит новую версию на GitHub, скачивает её в фоне, ставит и перезапускается.
Работает на стороне хоста, окно настроек для этого открывать не нужно. Выпуск версий: [process.md](../process.md).

## Устройство

- `updater.rs`: состояние `Updates` (статус, флаг `autoUpdate`, найденное обновление). Первая
  проверка через 30 секунд после запуска, дальше каждые 6 часов. Нашли обновление и
  `autoUpdate` включён: скачивание (проценты в статусе), проверка подписи, установщик NSIS в
  режиме `passive`, перезапуск. Выключено: статус `available`, кнопка «Установить» в настройках.
- Ошибки (нет сети, 404 пока нет релиза) только пишутся в лог и показываются текстом в блоке.
  Окон и уведомлений нет.
- В отладочной сборке (`pnpm tauri dev`) автоматических проверок нет; ручная кнопка работает.
- Перед установкой вызывается `desktop::shutdown`: окна обоев сразу прячутся через Win32 (не через UI-поток), поток слежения останавливается и больше не прикрепляет/показывает окна. Раньше окно отсоединялось (`SetParent(None)`) раньше, чем успевало спрятаться, и рисовалось поверх обычных окон. Обои на время установки пропадают на несколько секунд.
- Команды: `update_status`, `check_for_updates`, `install_update`; событие `deskwall://update`
  (`UpdatePayload`: `state`, `current`, `latest`, `progress`, `checkedAt`). Описано в
  [protocol.md](protocol.md), у формы есть тесты в TS и Rust.
- Настройка `autoUpdate` (по умолчанию включена).
- UI: блок «Обновления» в настройках обоих режимов (версия, переключатель, «Проверить сейчас»,
  текст статуса); пункт трея «Проверить обновления».
- Лента: `https://github.com/dreyn-dev/DeskWall/releases/latest/download/latest.json`
  (ключ `endpoints`). Публичный ключ minisign: `pubkey` там же. Приватный ключ вне репозитория.

## Известные проблемы и ограничения

- Версия 0.1.0 без блока обновлений установлена вручную; обновляться сама начнёт только с первой
  версии, где уже есть этот модуль.
- Установщик не подписан кодом Windows, поэтому SmartScreen может ругаться при первой ручной
  установке. Обновления через приложение его не вызывают.

## Как проверить

`cargo test` (форма статуса, проценты) и `pnpm test`. Вручную: поставить собранную версию,
выпустить версию выше в репозитории выпусков, нажать «Проверить сейчас».
