Privacy policy

DeskWall is a free, open-source live wallpaper for Windows. This page explains what the app and this website do with your data. Short version: nothing. We collect no personal data.

The DeskWall app

  • It has no accounts, no sign-in and no analytics, telemetry or crash reporting.
  • It does not read your files. It asks Windows only for the positions of desktop icons and for whether a full-screen window is open, to draw the wallpaper around them. Icon names and positions are used in memory and are never stored or sent anywhere.
  • Your settings (theme, palette, frame rate) are stored only in a local file on your computer.
  • No advertising, no third-party SDKs, no cookies.

Update checks

The app can check for a new version. To do that it requests a small file from GitHub Releases (github.com/dreyn-dev/DeskWall). Like any web request, GitHub sees your IP address and the app version in the request. DeskWall sends nothing else and does not combine this with any other data. GitHub's handling of requests is described in the GitHub Privacy Statement. You can turn update checks off in the app settings.

This website

The site is a static page hosted on GitHub Pages. We run no analytics or tracking scripts and set no cookies. Fonts and images are served from the same site. GitHub, as the host, may keep standard server logs; see the GitHub Privacy Statement above.

Children

DeskWall does not collect data from anyone, including children.

Changes

If this policy changes, the new version and its date will appear on this page, and the history is public in the repository.

Contact

Questions: open an issue at github.com/dreyn-dev/DeskWall/issues.
